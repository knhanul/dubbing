# 영상 합성기 (Video Composer) 🎬🎤

Grok 같은 AI 로 만든 **이미지·영상 클립을 AI 가 만든 JSON 프로젝트대로 자동 조립**하고,
**떨림 없는 이미지 움직임**, 전환 효과, 자막, 배경음악, **마이크 더빙**까지 넣어 MP4 로 만드는 Windows 데스크톱 프로그램입니다.

> AI 영상 도구의 자체 이어붙이기 기능은 이미지를 움직일 때 화면이 덜덜 떨리는 문제가 있습니다.
> 이 프로그램은 이미지 움직임을 소수점 좌표로 계산해서 매끄럽게 만듭니다(아래 [떨림 방지 원리](#떨림-방지-원리) 참고).

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🤖 **AI 로 구성하기** | 작업 폴더의 파일 목록과 규칙을 담은 프롬프트를 자동으로 만들어 줍니다. AI 에 붙여넣으면 JSON 만 답하게 됩니다. 답변을 붙여넣으면 **자동으로 검사**하고, 문제가 없으면 **✔ 적용**으로 타임라인에 반영합니다. |
| 📋 **AI 답변 자동 검사** | 답변에 ` ```json ` 코드블록이나 설명 문장이 섞여 있어도 JSON 만 찾아냅니다. 끝 쉼표·주석 같은 흔한 실수도 고쳐 읽습니다. 없는 파일, 잘못된 숫자 등을 **한국어로** 알려 주고, AI 에게 다시 보낼 **수정 요청 프롬프트**도 만들어 줍니다. |
| 🖱 **드래그 앤 드롭** | Windows 탐색기에서 이미지·영상·폴더·자막·음악·프로젝트(.json)를 창에 끌어다 놓으면 바로 추가됩니다. 타임라인에 놓으면 **놓은 위치에 삽입**, 여러 파일은 **이름의 숫자 순서**(img2 → img10)로 정렬됩니다. |
| 🎞 **타임라인 + 미리보기** | 클립·자막·더빙·배경음악 트랙을 막대로 보여 줍니다. 360p 미리보기를 **자동으로** 만들어 재생하고(편집하면 1.5초 뒤 알아서 다시 만듦), 자막은 화면 위에 실시간으로 그립니다. |
| 🛠 **선택 / 미세 조정** | 타임라인에서 고른 것(클립·전환·자막·더빙·배경음악)의 설정만 오른쪽 첫 탭에 나옵니다(탭 이름이 **🛠 클립 / 🛠 자막 / 🛠 더빙 …** 으로 바뀜). 숫자 칸은 접지 않고 바로 보이며 휠/화살표 = 0.1초, **Shift** = 0.01초. 타임라인에서 끌어서 옮기기/길이 바꾸기/순서 바꾸기, **🧲 자석**(Shift = 끄고 0.01초), **✂ 자르기 도구**. 실행 취소(Ctrl+Z) 지원. 모든 수정은 프로젝트 JSON 에 저장됩니다. |
| ✨ **효과** | 오른쪽 **✨ 효과** 탭에서 고른 클립에 **영상 움직임**(이미지·영상 모두, 떨림 없이), **색 필터**(흑백·세피아·빈티지·따뜻하게·차갑게·선명하게·영화톤, 그 장면으로 만든 작은 그림 카드), **밝기·색**(밝기·또렷함·색 진하기), **분위기**(모서리 어둡게·흐림·필름 노이즈)를 넣습니다. **모든 클립에 같은 효과** 한 번이면 전체에 똑같이. 영상 **처음·끝 검은 화면 페이드**는 📤 내보내기 탭. |
| 🎤 **더빙** | **다음 자막을 미리** 보여 주고 "N초 후 표시", 현재 자막은 "N초 후 사라짐"과 진행 막대를 보여 줍니다. 자막 줄마다 프리롤(미리 재생)과 함께 녹음, 다시 녹음, 들어 보기, 여기부터 연속 녹음, 마이크 선택, **입력 레벨 미터·흘러가는 파형·깜빡이는 ● REC·무음 경고·🎧 마이크 테스트**, 타임라인 더빙 파형, 녹음 중 원본 소리 줄이기. |
| 🎙→📝 **더빙 먼저, 자막은 나중에** | 대본을 보며 편하게 녹음(텔레프롬프터)한 뒤 **음성 인식(내 PC, faster-whisper) + 무음 감지**를 섞어 녹음에 맞는 자막(SRT)을 만듭니다. 대본 글은 그대로, 시간만 녹음에서. 확인이 필요한 자막은 **노란색**으로 표시하고, **자막 맞추기** 화면(파형 위 끌기·나누기·합치기·탭으로 맞추기)에서 쉽게 고칩니다. |
| ⚙ **ffmpeg 렌더** | 해상도/fps/픽셀 형식 통일(꽉 채우기 또는 여백), 속도 조절(atempo 자동 연결), 목표 길이 맞춤, xfade/acrossfade 전환, 자막 입히기 또는 소프트 자막, 더빙 + 배경음악 믹스와 **목소리 나올 때 음악 자동 줄이기(덕킹)**. NVIDIA GPU(NVENC) 자동 감지. 진행률 표시와 취소. |
| ⚡ **클립 캐시** | 클립별 중간 파일을 저장해 두고, 한 클립만 고치면 그 클립만 다시 만듭니다. |

## 설치와 실행 (Windows)

### 방법 1 — 파이썬으로 실행 (권장)

1. [python.org](https://www.python.org/downloads/) 에서 **Python 3.11 ~ 3.13** 을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"** 를 꼭 체크하세요.
2. 이 저장소를 내려받습니다.
   ```bat
   git clone https://github.com/knhanul/dubbing.git
   cd dubbing
   ```
   (git 이 없으면 GitHub 페이지의 **Code ▸ Download ZIP** 으로 받아 압축을 푸세요.)
3. **`run.bat`** 을 더블클릭합니다. 처음 한 번은 가상환경(.venv)을 만들고 필요한 패키지를 설치하느라 몇 분 걸립니다.

명령 프롬프트에서 직접 실행하려면:
```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m composer
:: 프로젝트 파일을 바로 열기
.venv\Scripts\python -m composer D:\작업\project.json
```

ffmpeg 는 따로 설치하지 않아도 됩니다(`imageio-ffmpeg` 패키지에 들어 있음). 직접 받은 ffmpeg 를 쓰려면
`ffmpeg.exe` 를 프로그램 폴더에 두거나 PATH 에 넣거나, 환경변수 `COMPOSER_FFMPEG` 에 경로를 지정하세요.

### 방법 2 — exe 만들기

**`build.bat`** 을 더블클릭하면 `dist\VideoComposer\VideoComposer.exe` 가 만들어집니다.
`dist\VideoComposer` **폴더 전체**를 원하는 곳에 복사해서 쓰면 됩니다(파이썬이 없는 PC 에서도 실행).

## 사용 순서

### 0. 파일 다루기 (보통 프로그램과 같음)
- 프로그램을 켜면 **'제목 없음'** 빈 화면으로 시작합니다. 가운데 안내처럼 *이미지·동영상을 끌어다 놓거나 'AI 로 구성하기'로 시작*하면 됩니다.
- **파일** 메뉴: **새로 만들기 (Ctrl+N)**, **열기 (Ctrl+O)**, **최근 파일**, **저장 (Ctrl+S)**, **다른 이름으로 저장 (Ctrl+Shift+S)**, **끝내기**.
- 새로 만들기는 폴더를 묻지 않습니다. 바뀐 내용이 있을 때만 저장할지 묻고 빈 '제목 없음' 프로젝트를 엽니다.
- 작업 폴더는 **처음 추가한 미디어 파일(끌어 놓기·클립 추가·자막/음악 선택)의 폴더**로 자동으로 정해집니다.
- 처음 저장할 때 프로젝트 안의 파일 경로는 **저장한 JSON 위치 기준 상대 경로로 다시 계산**되므로 어디에 저장해도 파일을 잘 찾습니다.

### 1. 폴더 준비
이미지(png/jpg/webp…), 영상(mp4/mov/webm…), 배경음악(mp3/wav/m4a…), 자막(srt/vtt)을 **한 폴더**에 넣습니다.
파일 이름에 순서를 붙여 두면(`01_바다.png`, `02_산책.mp4` …) AI 가 순서를 정하기 쉽습니다.

### 2. AI 로 구성하기 (JSON 받기 → 검사 → 적용)
1. **🤖 AI 로 구성하기 (Ctrl+Shift+A)** → 미디어가 들어 있는 폴더 선택(AI 에게 파일 목록을 알려 주기 위한 것).
2. "원하는 영상 설명"에 원하는 느낌을 적고(예: *30초 여행 브이로그, 사진은 천천히 확대, 영상은 소리 끄고*) **프롬프트 만들기** → **📋 프롬프트 복사**.
3. Grok 등 AI 에 붙여넣고 답을 받습니다.
4. **② AI 답변 붙여넣기** 탭에 답변 전체를 붙여넣습니다(**📋 클립보드에서 붙여넣기** 버튼도 가능). 붙여넣는 즉시 **자동으로 검사**합니다.
   - 문제가 있으면 목록에 빨간색(오류)/노란색(경고)으로 표시됩니다. **수정 요청 프롬프트 복사** → AI 에 보내고 새 답을 다시 붙여넣으세요.
   - 문제가 없으면 "✔ 문제 없음 — '적용'을 누르면 타임라인에 반영됩니다." 가 나오고 **✔ 적용** 버튼이 켜집니다.
5. **✔ 적용** → 창이 닫히고 현재 타임라인이 AI 결과로 바뀌며, **미리보기가 자동으로 만들어집니다**. 다른 질문 창은 뜨지 않습니다.
   - 마음에 들지 않으면 **Ctrl+Z 한 번**으로 바로 이전 타임라인으로 돌아갑니다.
   - 바뀌는 것: 클립·전환·출력 설정. 자막·배경음악은 AI 답변에 있을 때만 바뀌고, **직접 녹음한 더빙은 그대로** 남습니다.
   - 이미 저장한 프로젝트라면 같은 파일에 그대로 **Ctrl+S** 로 저장됩니다. 저장한 적이 없으면 창 제목에 `*` 가 붙고, Ctrl+S 를 누르면 작업 폴더의 `project.json` 을 기본 이름으로 보여 줍니다.

### 2-1. (또는) 드래그 앤 드롭으로 바로 만들기
AI 없이도 탐색기에서 파일을 끌어다 놓아 프로젝트를 만들 수 있습니다.

| 끌어 놓는 것 | 동작 |
|---|---|
| 이미지 / 영상 (여러 개 가능) | 클립으로 추가. **창 아무 곳**에 놓으면 끝에 추가, **타임라인**에 놓으면 놓은 위치에 삽입 |
| 폴더 | 안에 있는 이미지·영상(하위 폴더 포함)을 이름 순으로 추가, 자막·음악도 함께 설정 (`takes`, `.composer_cache` 폴더와 폴더 안의 .json 은 무시) |
| .srt / .vtt | 자막으로 설정 |
| .mp3 / .wav / .m4a / .flac / .ogg | 배경음악으로 설정 (이미 있으면 바꿀지 물어봄) |
| .json | 프로젝트 열기 (json 하나만 따로 놓았을 때) |
| 그 밖의 파일 | 건너뛰고 어떤 파일을 건너뛰었는지 한국어로 알려 줌 |

- **여러 파일을 넣을 때 순서 정하기**: 이미지·영상을 2개 이상 끌어 놓거나 **클립 추가**에서 여러 개 고르면 **"순서 정하기"** 창이 뜹니다.
  (Windows 탐색기는 파일을 선택한 순서를 프로그램에 알려 주지 않기 때문입니다.)
  - 썸네일(영상은 첫 장면 + 길이)을 **넣을 순서대로 차례로 클릭**하면 1, 2, 3… 번호가 붙습니다. 다시 클릭하면 번호가 빠지고 나머지가 당겨집니다.
  - 번호를 안 붙인 파일은 번호 붙은 파일 뒤에 화면 순서(처음엔 이름순)대로 들어갑니다. 썸네일을 **끌어서** 화면 순서를 바꿀 수도 있습니다.
  - 버튼: **✔ 이 순서로 넣기**, **이름순**(바로 이름순으로 넣기), **놓은 순서 그대로**(탐색기가 넘겨 준 순서), **초기화**(번호 지우기), **취소**(아무것도 넣지 않음).
  - **다음부터 묻지 않고 이름순** 을 체크하면 다음부터는 창 없이 이름순으로 넣습니다. 다시 켜려면 **➕ 미디어 추가 ▾ ▸ 새 이미지 기본값…**(또는 **편집 ▸ 새 이미지 기본값…**) 창에서 "여러 파일을 넣을 때 '순서 정하기'를 묻지 않고 이름순" 체크를 끄세요.
  - 놓은 위치(타임라인)에 그대로 삽입되고, Ctrl+Z 한 번으로 되돌릴 수 있습니다. 영상 썸네일은 사용자 캐시 폴더(`%LOCALAPPDATA%\VideoComposer\thumbs`)에 저장해 다음엔 바로 뜹니다.
- 이름순은 **자연스러운 이름 순서**입니다: `img1, img2, img10` (단순 문자 순서라면 img10 이 img2 앞에 옵니다).
- 타임라인 위로 끌고 오면 **파란 세로선**과 "클립 N개를 M번 자리에 삽입" 표시가 나타납니다. 클립의 가운데를 기준으로 앞/뒤가 정해집니다.
- 아무것도 없는 '제목 없음' 프로젝트에 처음 놓으면 그 파일(또는 폴더)이 있는 곳이 작업 폴더가 되고, 파일 경로는 프로젝트 기준 상대 경로로 저장됩니다.
- 한 번 끌어 놓은 것은 **Ctrl+Z 한 번**으로 모두 되돌릴 수 있습니다.
- 새로 추가되는 이미지의 **표시 시간(기본 4초)과 움직임**은 **➕ 미디어 추가 ▾ ▸ 새 이미지 기본값…** 창에서 바꿀 수 있고, 다음 실행 때도 기억됩니다.
- 클립 순서는 **타임라인에서 클립을 끌어서** 바꿉니다(예전 🎞 클립 목록 탭은 없앴습니다).

### 화면 구성 (한눈에)
```
┌ 위 도구 막대: 🤖 AI 로 구성하기 · 📂 열기 · 💾 저장 · ➕ 미디어 추가 ▾ · ↶ ↷ ············ [📤 영상 내보내기] ┐
│ 미리보기 (▶ 재생 · 🔄 새로 만들기)                         │ 오른쪽 탭: 🛠 선택 | 🎤 녹음 | 🅰 자막 | ✨ 효과 | 📤 내보내기 │
├ 타임라인 도구 막대 ────────────────────────────────────────────────────────────────────────────────┤
│ ↖ 선택(V) ✂ 자르기(C) 🗑 삭제 │ [In Out] ✂ 구간 잘라내기 ☑모든 트랙 │ 🧲 자석 │ ＋ 전환 ＋ 자막 ● 녹음 │ 🔍− ━━○━━ 🔍+ ⤢ 전체 보기 ⇥ 따라가기 │
│ 타임라인 (클립 · 자막 · 더빙 · 배경음악 트랙)                                                       │
└────────────────────────────────────────────────────────────────────────────────────────────────┘
```

- 오른쪽 패널은 **최소 폭 440px** 로 고정입니다(더 좁게는 안 줄어듦). 넓히면 **720px 부터 섹션이 2단**으로 나란히 놓입니다.
- 각 탭은 짧은 칸을 한 줄에 2~3개씩, 2~3개 중 고르기는 버튼 묶음으로, 섹션은 작은 제목 + 가는 줄로 보여 줍니다. 탭의 주 단추(녹음 · 효과 적용 · 내보내기)는 위나 바닥에 고정되어 스크롤해도 보입니다.

- 타임라인에서 클립·전환·배경음악을 고르면 자동으로 **🛠 선택** 탭으로 갑니다(**✨ 효과** 탭을 보고 있을 때 클립을 고르면 효과 탭 그대로). 자막·더빙은 **🎤 녹음** 탭을 보고 있을 때는 그대로 둡니다(녹음 흐름 유지).

### 3. 미리보기와 미세 조정
- **자동 미리보기**: 프로젝트를 열거나 AI 결과를 적용하면 360p 미리보기를 바로 만들기 시작합니다. 클립 길이·속도·자르기·순서·움직임·전환·배경음악을 고치면 **1.5초 뒤 백그라운드에서 다시** 만듭니다(바뀐 클립만 새로 만들고 나머지는 캐시 사용).
- **미리보기 소리**: 클립 원본 소리는 미리보기 영상에, **배경음악**은 따로 만든 소리 파일로, **더빙**은 녹음 파일 그대로 재생 위치에 맞춰 함께 틉니다(재생을 더빙 조각 가운데서 시작해도 그 자리부터 들림). 배경음악을 넣거나 바꾸면 잠깐 뒤 준비되고, 재생 중이면 상태 표시줄에 **♪ 배경음악 준비 중…** 이 뜹니다. 준비에 실패하면 이유를 알려 주고, 재생을 다시 누르면 한 번 더 시도합니다. 미리보기 영상을 만들기 전(타임라인 시간으로 재생)에는 클립 원본 소리는 나오지 않고 배경음악·더빙만 들립니다.
  - 만드는 동안에는 영상 가운데에 "미리보기 만드는 중… 40%" 가 나오고, 예전 미리보기는 계속 재생됩니다. 새 것이 준비되면 **재생 위치를 그대로 유지한 채** 바뀝니다.
  - 만드는 도중 또 고치면 진행 중인 렌더를 취소하고 다시 시작합니다.
  - 미리보기가 아직 없을 때 재생하면 **타임라인 시간**으로 재생하며 현재 클립 그림과 자막을 보여 줍니다(더빙 패널도 같은 시간을 따라감).
  - 재생 버튼 옆 **🔄 미리보기 새로 만들기**(F5)로 언제든 바로 다시 만들 수 있습니다.
  - 자동이 싫으면 **보기 ▸ 자동 미리보기** 를 끄세요(설정은 기억됨). 자막과 더빙은 렌더 없이 항상 바로 반영됩니다.
- **타임라인 (프리미어 방식)**: 클립들은 **맞닿게** 이어지고(전체 길이 = 클립 길이의 합), 전환은 두 클립 **경계 가운데에 걸친 작은 블록**(이름 + 길이)으로 클립 트랙 아래쪽에 보입니다.
  - **클립 길이 바꾸기**: 클립 **오른쪽 끝**(또는 **왼쪽 끝**)에 마우스를 올리면 노란 선과 ↔ 커서가 나옵니다. 끌면 길이가 바뀝니다(Shift = 0.01초). 왼쪽 끝은 동영상이면 **시작 부분 자르기/되살리기**, 이미지면 길이입니다. 클립 끝은 트랙 **위쪽 절반**에서 잡으세요(아래쪽은 전환 블록).
  - **전환 블록**: 클릭 = 고르기(🛠 전환에서 **방식·시간**), **양 끝 끌기** = 길이(가운데 고정, 양쪽으로 같이), **Delete** = 전환 없애기. 전환 길이는 앞뒤 클립 중 짧은 쪽 길이를 넘지 않게 자동으로 줄어듭니다.
  - 전환은 앞 클립 끝 뒤와 뒤 클립 시작 앞의 **여분**을 씁니다. 이미지는 여분이 무한하고, 동영상은 자른 바깥 원본을 쓰며 모자라면 첫/끝 화면을 멈춰서 채웁니다. 그래서 화면에 보이는 시간 = 내보낸 영상 시간입니다.
  - 예전 형식(전환이 클립을 겹쳐 놓던 version 1) 프로젝트는 열 때 **보이는 시간이 같도록 자동으로 바뀝니다**(저장하면 새 형식).
- **✂ 자르기와 삭제** (타임라인 도구 막대, 오른쪽 클릭 메뉴, 편집 메뉴):
  - **✂ 자르기 도구 (C)**: 켜면 마우스 위치에 노란 점선이 보이고, 클립·자막·더빙을 **누른 곳에서** 바로 자릅니다(계속 켜져 있음). **↖ 선택 (V)** 또는 **Esc** 로 돌아갑니다.
  - **재생 위치에서 자르기 (Ctrl+K)**: 빨간 재생 위치에서 고른 클립·자막·더빙을 둘로 나눕니다(아무것도 안 골랐으면 재생 위치 아래 클립). 동영상은 같은 파일을 앞/뒤 구간으로 나누고(속도 반영), 이미지는 길이를 나누며 움직임이 이어집니다. 자막은 글도 시간 비율에 맞춰 나뉘고, 더빙은 원본 녹음 파일은 그대로 두고 앞/뒤 구간만 나눠 가리킵니다. 새로 자른 경계에는 전환이 없고, 원래 있던 전환은 그대로입니다.
  - **🗑 삭제 (Delete)**: 고른 조각을 지웁니다. 클립은 뒤 클립이 **당겨 붙습니다**(리플 삭제).
  - **구간 잘라내기**: 재생 위치에서 **I**(In)·**O**(Out)를 누르거나 **[ In / Out ]** 버튼(오른쪽 클릭 ▸ 여기를 In/Out 으로)으로 구간을 표시하면 눈금자에 빨갛게 보입니다. **✂ 구간 잘라내기** → 그 구간을 클립에서 빼고 뒤를 당겨 붙입니다. **모든 트랙**(기본 켜짐)이면 자막·더빙도 같은 구간을 빼고 함께 당깁니다(걸친 자막은 짧아지고, 걸친 더빙은 앞/뒤 조각으로 나뉨).
  - 잠긴(🔒) 트랙은 자르지 않습니다. 모두 **Ctrl+Z 한 번**으로 되돌립니다.
- **여러 개 고르기 (같은 트랙끼리)**: **Ctrl+클릭** = 더하기/빼기, **Shift+클릭** = 고른 것부터 거기까지 범위, 트랙의 **빈 곳에서 끌기** = 상자에 걸친 것 모두(Ctrl/Shift 를 누르고 시작하면 더하기), **Ctrl+A**(오른쪽 클릭 ▸ ☑ 모두 고르기) = 고른 트랙(없으면 클립) 전부. 클립·자막·더빙·전환은 각각 같은 종류끼리만 함께 고릅니다(다른 트랙을 Ctrl+클릭하면 새로 고름). 타임라인 오른쪽 위에 "자막 3개 고름"처럼 보입니다.
  - 고른 것 중 하나를 **끌면 함께 이동**(자막·더빙은 같은 만큼, 클립은 원래 순서대로 묶어서 순서 이동). 끌지 않고 누르기만 하면 그것 하나만 고릅니다. **[ ]**, **Delete** 도 고른 것 모두에 적용되고 **Ctrl+Z 한 번**으로 되돌립니다. 끝 끌기(길이 조절)·자르기·🛠 속성 탭은 마지막에 고른 것 하나만.
  - Shift+클릭은 끌지 않고 놓을 때만 범위 고르기라서, **Shift+끌기**(자석 끄고 0.01초)는 예전처럼 그 항목 하나만 움직입니다.
- **🧲 자석**(기본 켜짐, 상태 기억): 끌 때 클립 경계·재생 위치·자막·더빙 시작/끝·In/Out 에 8픽셀 안이면 붙습니다. **Shift** 를 누르고 끌면 자석이 꺼지고 0.01초 단위.
- **＋ 전환**: 재생 위치에서 가장 가까운 클립 경계에 기본 전환(📤 내보내기 탭 ▸ 장면 바뀔 때, '없음'이면 크로스페이드 0.5초)을 넣습니다. **＋ 자막**: 재생 위치에 '새 자막' 2초(다른 자막과 겹치지 않게)를 넣고 글 칸으로 갑니다. **● 녹음 (R)**: 🎤 녹음 탭으로 가서 **● 이 줄 녹음**(고른 자막, 없으면 재생 위치의 자막), 자막이 없으면 자유 녹음.
- 빈 배경음악·자막 트랙에는 **＋ 음악 넣기 / ＋ 자막 파일 불러오기** 버튼이 보입니다. 확대·축소는 **🔍− / 막대 / 🔍+**, **⤢ 전체 보기 (Ctrl+0)**.
- 타임라인에서 항목을 클릭하면 오른쪽 **🛠 선택** 탭(이름이 🛠 클립 / 🛠 자막 … 으로 바뀜)에 그 항목의 설정이 나옵니다. 숫자 칸은 접지 않고 바로 보이며, 지우기·복제는 머리줄 오른쪽 작은 아이콘(🗑 · ⧉)입니다.
  - 클립: **길이·속도**(이미지 = 보이는 시간, 영상 = 재생 속도 목록 + 배속 칸, 목표 길이에 맞춰 속도 자동), **화면**(화면 맞춤 버튼 묶음 기본값/꽉 채우기/전체 보이기, 이름표), **효과**(지금 넣은 효과 요약 + ✨ 효과 탭에서 바꾸기), 영상이면 **원본 영상**(앞 자르기 · 끝 자르기 · 원본 소리 끄기·크기). ⧉ 복제 · 🗑 삭제는 머리줄 아이콘
  - 전환: 종류, 길이(슬라이더), 🗑 전환 없애기
  - 자막: 내용, 🅰 모양 바꾸기(→ 🅰 자막 탭), 🗑 삭제. 숫자 칸: 시작/끝, "이후 자막 모두 이동" (타임라인에서 **Delete** 키, **[ ]** 키로 0.1초 이동도 됨)
  - 더빙: 볼륨, ▶ 듣기 · ▶ 영상과 함께 듣기 · ● 다시 녹음, 🗑 삭제. 숫자 칸: 위치(오프셋)
  - 배경음악: 파일 바꾸기…, 볼륨·페이드 인/아웃(슬라이더), 반복, 목소리 나올 때 줄이기, 🗑 배경음악 빼기. 숫자 칸: 시작, 파일 내 시작 위치, 페이드, 줄이는 정도
  - **자막 전체 제거**: **🅰 자막 탭 ▸ 자막 파일 ▸ 🗑 자막 전체 빼기** 버튼(또는 **편집 ▸ 자막 전체 제거**)을 누르고 확인하면 프로젝트에서 자막이 모두 빠집니다.
    **원본 SRT 파일은 지워지지 않으며**, Ctrl+Z 한 번으로 되돌릴 수 있습니다. 자막에 연결돼 있던 더빙 녹음은 지금 위치에 그대로 고정됩니다.
  - **배경음악 제거**: 배경음악 막대를 고른 뒤 **🛠 음악 ▸ 🗑 배경음악 빼기** 버튼, **편집 ▸ 배경음악 제거**, 또는 타임라인에서 배경음악 막대를 고르고 **Delete**. 한 번 확인하면 프로젝트에서 음악이 빠지고 미리보기가 자동으로 다시 만들어집니다. **원본 음악 파일은 지워지지 않으며**, Ctrl+Z 한 번으로 되돌립니다(볼륨·페이드 설정도 그대로).
  - 아무것도 고르지 않았을 때는 **시작하기 단계표**가 나옵니다. 다 한 단계는 ✓, 지금 할 일(예: '3줄 중 1줄 녹음함 · ● 이어서 녹음')은 파란 테두리와 단추로 보여 주며, **● 이어서 녹음** 을 누르면 🎤 녹음 탭에서 아직 녹음 안 한 첫 줄을 골라 줍니다.

### 3-0. ✨ 효과 탭 (고른 클립의 색 · 분위기 · 움직임)
타임라인에서 클립을 고르고 오른쪽 **✨ 효과** 탭을 엽니다(🛠 클립의 **✨ 효과 탭에서 바꾸기** 버튼으로도). 아무것도 안 골랐으면 "타임라인에서 클립을 선택하세요"가 나옵니다.
- **맨 위 합쳐 보기 그림**(최대 높이 150px): 고른 클립의 한 장면에 **지금 효과를 모두 합친 모습**(색 필터 + 밝기·색 + 모서리 어둡게·흐림·노이즈)을 보여 줍니다. 오른쪽 **원래 / 효과 적용** 으로 넣기 전 모습과 비교. 내보내기와 **같은 ffmpeg 필터**로 만들며(움직임은 빼고 한 장면, 영상은 가운데쯤 장면), 값을 바꾸면 **0.3초 뒤** 백그라운드에서 다시 만듭니다. 만드는 동안 그림 위에 **만드는 중…** 이 잠깐 뜨고, 같은 값은 저장해 둔 그림을 바로 씁니다.
- **느린 PC 에서도 버벅이지 않게**: 슬라이더는 **손을 뗄 때 한 번만** 반영하고(끄는 동안은 숫자만 바뀜), 그림은 원본을 **960px 이하로 한 번 줄여 둔 그림**으로 만들며(큰 사진·영상을 매번 다시 읽지 않음), 그림 만드는 일은 **한 번에 하나씩 · 낮은 우선순위**로 돌립니다. **✨ 효과 탭에 있는 동안에는 미리보기 영상 전체를 다시 만들지 않고** 기다렸다가, 다른 탭으로 가거나 ▶ 재생하면 그때 만듭니다(미리보기 영상 만들기도 낮은 우선순위).
- 아래는 접고 펼 수 있는 **카드 4개**입니다. 카드 머리를 누르면 접히고(상태 기억), 접힌 머리에는 지금 값이 짧게 나옵니다(예: `색 필터 — 빈티지`, `밝기 +10 · 색 진하기 -5`, `모서리 어둡게 30`). 기본값에서 바꾼 것이 있는 카드는 제목 옆에 **노란 점(●)** 이 붙습니다.
  - **색 필터**: 없음(원본) · 흑백 · 세피아 · 빈티지 · 따뜻하게 · 차갑게 · 선명하게 · 영화톤. 카드 그림은 **"이 필터 + 지금 내 다른 조정(밝기·색·분위기)"** 으로 보여 줘서 고르면 어떻게 될지 바로 알 수 있습니다.
  - **밝기 · 색**(밝기 · 또렷함(대비) · 색 진하기(채도)): 한 줄에 `이름 | 슬라이더 | 값 | ↺`. 값은 기본 0 기준(+10, -5 …), **↺** = 기본값으로.
  - **분위기**: 모서리 어둡게(비네팅) · 흐림 · 필름 노이즈(0~100).
  - **움직임**: 종류(확대/이동/켄 번스) · 강도 · 속도감. **이미지와 동영상 모두** 됩니다(영상도 소수점 좌표로 매끄럽게, 자르면 움직임이 이어짐).
- 모든 값은 **바꾸는 즉시** 클립에 적용됩니다(Ctrl+Z 로 되돌리기, 슬라이더 한 번 끌기 = 한 단계).
- **모든 클립에 적용**: 이 클립의 색·조정·분위기·움직임을 모든 클립에 똑같이(Ctrl+Z 한 번으로 되돌리기). **효과 지우기**: 색·조정·분위기를 기본값으로(움직임은 그대로).
- 효과가 있는 클립은 타임라인 막대 오른쪽 위에 **✨** 표시가 붙습니다. 클립 트랙이 🔒 잠겨 있으면 바뀌지 않습니다. ✂ 자르기로 나누면 양쪽 조각에 효과가 그대로 복사됩니다.
- 타임라인 **미리보기 영상**도 효과를 바꾸면 1.5초 뒤 360p 로 자동으로 다시 만들어져 모든 효과(움직임 포함)가 보입니다(바뀐 클립만 새로 만듦).

### 3-0. 📤 내보내기 탭 (프로젝트 전체 설정)
오른쪽 패널에 **항상 있는 📤 내보내기** 탭에 영상 전체에 적용되는 설정이 모여 있습니다(거의 안 바꾸는 것은 **▸ 자세히** 안). 바닥에는 결과 요약과 **📤 영상 내보내기** 단추가 늘 보입니다(녹음 안 한 자막 줄이 있으면 요약에 ⚠).
- **영상 크기**: `1920×1080 가로 (유튜브)`, `1080×1920 세로 (쇼츠·릴스·틱톡)`, `1280×720 가로 (HD · 가볍게)`, `720×1280 세로`,
  `1080×1080 정사각 (인스타 피드)`, `1080×1350 세로 4:5 (인스타 피드)`, `2560×1440 가로 (QHD)`, `3840×2160 가로 (4K 유튜브)`, 또는 **직접 입력**(가로×세로)
- 위쪽 **영상 모양**(▭ 가로 16:9 · 유튜브 / ▯ 세로 9:16 · 쇼츠 / □ 1:1)으로 한 번에 고르거나 목록에서 고릅니다. 화면 맞춤(꽉 채우기/전체 보이기)
- **처음 · 끝**(나타나기 · 사라지기 = 페이드): 처음에 검은 화면에서 밝아지기 / 끝에서 검은 화면으로(0~5초). 소리도 같이 작아졌다 커집니다.
- **장면 바뀔 때**(기본 전환 방식·시간) + **모든 경계에 적용**(클립마다 따로 정한 전환을 지우고 기본 전환으로, Ctrl+Z 로 되돌리기), 자막 넣는 방식(영상에 새기기 / 따로 켜고 끄는 자막)
- **▸ 자세히**: 가로×세로, 초당 장면 수(fps), 여백 색, 원본 소리, 목소리 소리, 목소리 밀림(녹음 지연 보정), 자막 전체 늦추기(오프셋), 녹음 폴더. 출력 파일 이름은 내보내기 창에서 정합니다.
- 배경음악 설정은 타임라인의 **배경음악 막대를 고르면 🛠 음악** 탭에 나옵니다. 자막 파일은 **🅰 자막** 탭 맨 위.
- 영상 크기·fps 를 바꾸면 미리보기가 자동으로 다시 만들어집니다.
- **영상 내보내기** 창에도 영상 크기·fps 가 나오며, 거기서 바꾸면 이 탭(프로젝트)에도 반영됩니다(Ctrl+Z 로 되돌리기 가능).
- 타임라인 마우스 조작
  - 클립 끌기 = 순서 바꾸기, 클립 오른쪽 끝 끌기 = 길이 조절
  - 자막 끌기 = 이동, 자막 양 끝 끌기 = 시작/끝 조절
  - 더빙·배경음악 끌기 = 위치 이동, 더빙 조각 **양 끝 끌기** = 들리는 길이 조절(파일 안 구간)
  - **더빙 조각 겹침**: 겹친 곳은 두 목소리가 **동시에** 들리므로 더빙 트랙에 **빨간 빗금**으로 표시합니다.
    더빙 조각을 끌어 다른 조각과 겹치게 놓으면 **옆 조각의 앞 끝/뒤 끝 중 가까운 쪽에 자동으로 붙습니다**(일부러 겹치려면 **Shift** 를 누른 채 놓기).
    끝을 끌어 길이를 늘일 때도 옆 조각에 닿으면 멈춥니다(Shift = 겹쳐도 됨). 자르기는 겹침을 만들지 않습니다.
    새로 녹음한 조각이 기존 조각과 겹치면 옮기지 않고 표시만 합니다(같은 자막을 다시 녹음하면 예전처럼 그 줄의 녹음을 바꿈).
  - **Shift 를 누르고 끌면 0.01초 단위**, Ctrl + 휠 = 확대/축소, 눈금 클릭 = 재생 위치 이동

### 3-0. 트랙 켜고 끄기 (타임라인 왼쪽 트랙 머리, 프리미어처럼)
타임라인 각 줄 왼쪽 머리에 단추가 있습니다(가로로 스크롤해도 늘 보임). 누를 때마다 프로젝트 JSON 의 `tracks` 에 기록되고 **Ctrl+Z** 로 하나씩 되돌립니다.

| 단추 | 트랙 | 하는 일 |
|---|---|---|
| 👁 감추기 (켜지면 🚫 빨강) | 클립 | 화면을 검게(배경색) — 미리보기·내보내기 모두. 소리는 그대로 |
| | 자막 | 화면 위 자막 표시, 새기기, 소프트 자막 모두 빠짐 (자막에 붙은 더빙은 제자리) |
| 🔊/🔇 소리 끄기 (켜지면 빨강) | 클립(원본 소리)·더빙·배경음악 | 그 트랙 소리 끄기 |
| S 솔로 (켜지면 노랑) | 클립·더빙·배경음악 | 솔로 켠 트랙 소리만 들림(여러 개 가능). 🔇 가 솔로보다 우선 |
| 🔓/🔒 잠금 (켜지면 회색) | 모든 트랙 | 끌기·길이 조절·Delete·화살표 이동·미세 조정·끌어 놓기 추가·제거 기능을 막음(고르기는 됨). 빗금으로 표시 |

- 감추거나 안 들리는 트랙은 흐리게 그려집니다. 단추 풍선 도움말에 지금 상태가 한국어로 나옵니다.
- **미리보기**: 🔇/S 는 소리 크기만 바꿔 **바로** 반영됩니다(다시 렌더 없음). 배경음악은 미리보기 영상과 따로
  '배경음악만 있는 WAV'(반복·페이드·더빙 밑 줄이기 포함)를 몇 초 만에 만들어 같이 틀기 때문입니다.
  자막 감추기도 바로 반영. **클립 👁 감추기**는 자동 미리보기를 다시 만듭니다(캐시 덕분에 조립만 다시).
- **영상 내보내기**: 트랙 설정을 그대로 따릅니다. 하나라도 감추거나 소리가 꺼져 있으면 내보내기 창 맨 위에
  **"⚠ 감춰지거나 음소거된 트랙이 있습니다: …"** 경고가 나옵니다.

### 3-1. 자막 (🅰 자막 탭)
오른쪽 패널의 **🅰 자막** 탭(항상 있음)에서 자막 파일과 자막 모양을 정합니다. 맨 위 **자막 파일** 칸: **📝 불러오기…**(SRT/VTT), **💾 SRT 로 저장…**(고친 자막·자동으로 만든 자막 포함), **🗑 자막 전체 빼기**.

**스타일 모음 (탭 맨 위)** — 썸네일을 누르면 바로 적용됩니다(프로젝트 JSON 의 `subtitle.style` 에 기록, **Ctrl+Z 한 번**으로 되돌리기).

| 기본 스타일 | 모양 |
|---|---|
| 유튜브 기본 | 흰 글자 + 검은 외곽선, 아래 |
| 쇼츠 강조 | 크고 굵은 노란 글자, 두꺼운 외곽선, 화면 아래쪽 가운데(높이의 24%), 톡 튀어나오기 |
| 뉴스 자막 | 아래 반투명 어두운 상자 + 흰 글자, 페이드 |
| 영화 자막 | 작은 흰 글자, 얇은 외곽선, 페이드 |
| 감성 시 | 가운데, 명조 글꼴(나눔명조 → 바탕 → Noto Serif CJK …), 타이핑 |
| 깔끔 박스 | 흰 상자 + 검은 글자 |

- 크기·외곽선·여백은 **현재 영상 크기(짧은 변)에 맞춰** 자동으로 늘이고 줄입니다(가로·세로 영상 모두 같은 비율).
- 글꼴이 PC 에 없으면 후보 글꼴 → 맑은 고딕 순으로 대신 씁니다(썸네일 풍선 도움말에 표시).
- **내 스타일로 저장…**: 지금 모양을 이름 붙여 저장(★ 표시). 같은 이름이면 덮어쓸지 묻습니다. **이름 바꾸기… / 삭제 / 내보내기 / 가져오기**는 **⋯** 메뉴에 있습니다(이름 바꾸기·삭제는 내 스타일만).
- 내 스타일은 `%LOCALAPPDATA%\VideoComposer\subtitle_presets.json` 에 저장되어 모든 프로젝트에서 씁니다.
- **내보내기… / 가져오기…**: 내 스타일을 JSON 파일로 주고받습니다(`{"presets":[{"name":..,"style":{..}}]}` 또는 `style` 객체 하나). 잘못된 값은 한국어로 알려 줍니다.
**빠른 조정**(크기·위치·배경 상자)은 늘 보이고, 나머지 묶음은 **▸ 자세히** 를 펼치면 나옵니다. 위쪽 견본 화면이 현재 설정으로 효과를 반복해서 보여 줍니다(**▶ 효과 다시 보기**).

| 묶음 | 설정 |
|---|---|
| 글꼴 | 글꼴 목록(설치된 글꼴, 기본은 **한글 글꼴만 보기**) + 한글 견본, 크기(px), 굵게 |
| 색 | 글자 색, 외곽선 색·두께, **배경 상자**(색·불투명도·여백) |
| 위치 | **아래 / 가운데 / 위** + 가장자리 여백(px, 아래·위일 때) |
| 나타나기 | **그냥 / 페이드 / 타이핑 / 아래에서 올라오기 / 톡 튀어나오기** + 효과 시간(초) |

- 바꾸는 즉시 프로젝트 JSON(`subtitle.style`)에 기록되고 **미리보기 화면 위 자막에 바로 반영**됩니다. 미리보기 자막은 화면 위에 실시간으로 그리므로 **미리보기 영상을 다시 만들지 않습니다**.
- 영상을 내보낼 때는 같은 설정으로 **ASS 자막 파일**을 만들어 영상에 새깁니다(배경 상자는 별도 층, 타이핑은 글자별 카라오케 태그, 올라오기는 `\move`, 톡 튀어나오기는 크기 애니메이션).
  미리보기의 효과는 비슷하게 흉내 낸 것이라 실제와 몇 픽셀·몇 프레임 다를 수 있습니다.
- 효과 시간은 자막 길이의 절반을 넘지 않게 자동으로 줄어듭니다. 타이핑은 효과 시간 동안 한 줄을 다 치며, 글자가 많으면 글자당 최소 0.04초입니다.
- **소프트 자막**(📤 내보내기 ▸ 자막 넣는 방식 ▸ '따로 (켜고 끌 수 있게)')으로 내보내면 스타일·효과는 적용되지 않습니다(재생 프로그램이 정함). 탭에 안내가 나옵니다.
- **기본값으로** 버튼, Ctrl+Z 로 되돌리기 가능.

### 4. 더빙 (마이크 녹음)
오른쪽 **🎤 녹음** 탭(맨 위 **🎤 자막 보며 녹음 / 🎙 자유롭게 녹음** 단추로 방식 고르기, 그 아래 마이크 한 줄은 두 방식이 함께 씀):
- **지금 자막** 카드에 현재 자막(N초 후 사라짐 + 진행 막대)과 **다음** 자막(N초 후 표시)이 나옵니다. 3초 전부터 숫자 카운트다운이 뜹니다.
- 자막 목록에서 줄을 고르고 **● 이 줄 녹음 (R)** → 프리롤(기본 2초) 전부터 영상이 재생되며 녹음되고, **자막이 끝나면(+ 끝난 뒤 여유, 기본 0.5초) 자동으로 멈춥니다**.
  - 그때 **아직 말하고 있으면** 바로 멈추지 않고 화면에 **● 말이 끝날 때까지 녹음 중…** 이 뜨며, 말소리가 **0.4초 동안 끊기면** 멈춥니다. 주변이 시끄러워 소리가 계속 들려도 **자막 끝에서 최대 5초**까지만 더 녹음합니다(그렇게 멈추면 상태 표시줄에 알려 줌).
  - 언제든 직접 끝낼 수도 있습니다: **R**(다시 누르기)·**스페이스**·**■ 정지**, 또는 녹음 중 **■ 녹음 끝내기 (R)** 로 바뀐 버튼.
  - 끝내면 녹음 끝의 무음을 찾아 더빙 조각에서 잘라 냅니다(마지막 말소리 + 0.3초, 원본 파일은 그대로).
  - 목소리가 자막보다 늦게 끝나면 **그 자막의 끝을 목소리 끝(마지막 말소리 + 0.2초)까지 자동으로 늘립니다**(줄이지는 않음). 다음 자막과 겹치게 되면 다음 자막 바로 앞까지만 늘리고 상태 표시줄에 알려 줍니다. 자막 트랙이 🔒 잠겨 있으면 늘리지 않습니다.
  - 녹음과 자막 늘리기는 **Ctrl+Z 한 번**으로 함께 되돌립니다. 같은 줄을 다시 녹음하면 새 버전(이전 파일은 지워지지 않음).
- **● 여기부터 계속 (Shift+R)**: 지금 재생 위치부터 영상 끝까지 이어서 녹음합니다.
- **소리가 들어오는지 보기** (탭 위쪽 마이크 줄, 두 방식 공통):
  - **입력 레벨 미터**: 말할 때 **초록~노랑**이면 알맞고, **빨강**이면 너무 큽니다. 오른쪽 **CLIP** 이 빨갛게 켜지면 소리가 찌그러진 것이니 마이크를 조금 멀리 하거나 Windows 입력 볼륨을 낮추세요. 흰 선 = 최근 가장 큰 소리.
  - **흘러가는 파형**: 들어오는 소리 모양이 오른쪽에서 왼쪽으로 흘러갑니다(녹음 중 빨강, 테스트 중 초록).
  - 녹음 중에는 빨간 **● REC** 가 깜빡이고 옆에 **녹음 시간**이 나옵니다.
  - **🎧 테스트**(마이크 줄): 녹음하지 않고 소리 크기만 봅니다. 🎤 목록에서 마이크를 고르세요(★ = Windows 기본 장치, 새로 꽂았으면 **↻ 장치 새로고침**).
  - 녹음 중 **3초 넘게 거의 소리가 없으면** "마이크 소리가 들어오지 않아요. 장치와 Windows 마이크 권한을 확인하세요" 가 뜹니다(Windows 설정 ▸ 개인 정보 ▸ 마이크 ▸ 데스크톱 앱 허용 확인). 소리가 들어오면 사라집니다.
  - 녹음이 끝나면 타임라인 **더빙** 트랙 막대 안에 **녹음 파형**이 보여 어디서 말했는지 알 수 있습니다.
- **▸ 녹음 설정**(접혀 있음): **시작 전 듣기**(프리롤, 녹음 직전에 앞부분을 들려줌), **끝난 뒤 여유**(한 줄 녹음이 자막 끝 뒤 얼마나 더 녹음할지), **녹음 중 원본**(원본 소리 크기, 기본 20%, 헤드폰 권장), 녹음 후 다음 줄로, 재생할 때 녹음 함께 듣기.
- 목록 머리에 **자막 N줄 · 녹음 M줄** 진행률과 **안 한 줄만 보기**가 있습니다. 좁은 패널에서는 끝·길이 열은 숨기고(줄에 마우스를 올리면 보임) 번호·시작·내용·녹음만 보입니다.
- 목록에서 줄을 **더블클릭**하면 녹음이 있으면 들어 보고, 없으면 그 자리로 갑니다. 녹음 듣기·다시 녹음은 타임라인에서 더빙 조각을 골라 🛠 더빙에서도 됩니다.
- 녹음 파일은 프로젝트 폴더의 `takes\` 에 WAV 로 저장되고 프로젝트에 자동 등록됩니다.
- **녹음본 고르기 (같은 줄을 여러 번·여러 목소리로 녹음해 두고 고르기)**: 같은 자막을 다시 녹음하면 예전 파일(`line_0003_v1.wav`, `_v2` …)은 지워지지 않고 남습니다.
  타임라인에서 더빙 조각을 고르면 **🛠 더빙** 맨 위(▶ 듣기 · ▶ 영상과 함께 · ● 다시 녹음 바로 아래)에 **녹음본 N개 — 하나를 골라 쓰세요** 목록이 v1, v2 … **녹음 시각 · 길이**와 함께 나오고, 지금 쓰는 것에 **✔ … 지금 사용** 표시가 붙습니다.
  - **◉ 동그라미** = 이 조각이 그 녹음본을 쓰게(위치·볼륨·자르기 구간은 그대로, 새 파일보다 길면 맞춰 줄임, **Ctrl+Z** 로 되돌리기)
  - **▶** = 그 녹음본을 **이 조각 자리에서 영상과 함께** 듣기(입 모양·타이밍 비교)
  - **✎** = 녹음본 이름(예: 밝게, 차분하게, 민수), **☆/★** = 마음에 드는 것 표시. 이름·★ 은 프로젝트 JSON `dubbing.notes` 에 저장되고 Ctrl+Z 로 되돌릴 수 있습니다(녹음 파일 이름은 그대로).
  - **🗑** = 그 녹음 파일 지우기(확인 후, **되돌릴 수 없음**, 그 녹음본의 이름·★ 도 정리). 지금 쓰는 녹음은 지울 수 없습니다.
  - 🎤 녹음 탭 목록의 '녹음' 칸에 **✔ 3개 ▾** 처럼 녹음본 수가 나오고, **누르면 그 자리에서 녹음본을 고르는 메뉴**(이름·★·시각·길이)가 열립니다.
  - 자유 녹음·연속 녹음·불러온 파일은 그 파일 하나만 보입니다. 더빙 트랙이 🔒 잠겨 있으면 바꿀 수 없습니다.
- 목소리가 늘 조금 늦게 들리면 **📤 내보내기 ▸ ▸ 자세히 ▸ 목소리 밀림(ms)**(녹음 지연 보정)을 올리세요.
- 자막 파일만 있는 완성 영상에 목소리만 입히고 싶다면 **파일 ▸ 동영상 + 자막으로 더빙 시작** 을 쓰세요(렌더 없이 원본을 바로 재생).

### 4-1. 더빙 먼저 → 자막 만들기 (🎙 자유 녹음 (대본 먼저))
자막 시간에 맞춰 읽기가 어렵다면, **먼저 편하게 녹음하고 자막을 녹음에 맞춰 만드세요.**
오른쪽 **🎤 녹음** 탭 ▸ 위쪽 **🎙 자유 녹음 (대본 먼저)** 단추:

1. **① 대본** — 대본을 붙여 넣거나 **대본 파일 열기…**(TXT/SRT/VTT/DOCX), 또는 **지금 자막에서 가져오기**. 대본이 없어도 됩니다(그러면 인식한 글을 씁니다).
2. **② 보면서 읽기 (텔레프롬프터)** — 대본이 크게 보입니다. **자동으로 넘기기**(자/초)를 켜면 녹음하는 동안 저절로 올라갑니다.
3. **③ 녹음** — 재생 위치를 정하고 **● 자유 녹음 시작** → 다 읽으면 **■ 녹음 끝내기**. 한 번에 길게, 또는 문장마다 끊어서 여러 번 녹음해도 됩니다(녹음은 그때 재생 위치에 놓이고, 다음 녹음은 이어서). **영상을 재생하면서 녹음**을 끄면 화면은 멈춘 채 녹음합니다. 이미 녹음한 파일은 **📂 음성 파일 불러오기…**(WAV/MP3 등).
4. **④ 자막 만들기** — **🎙→📝 더빙으로 자막 만들기**. 진행률과 취소 버튼이 나오고, 끝나면 **자막 맞추기** 화면이 열립니다. 확인하고 **✔ 적용**을 누르면 자막 트랙에 들어갑니다(Ctrl+Z 로 되돌리기). SRT 파일로 따로 저장하려면 **🅰 자막 탭 ▸ 💾 SRT 로 저장…**. 인식 방법·모델·글자 수·최소 시간은 **▸ 자막 만들기 옵션**(접혀 있음)에 있습니다.
   - 인식 방법 **자동**: 음성 인식 + 무음 감지를 섞습니다. 음성 인식(Whisper)이 단어마다 시각을 알려 주면 대본 문장과 글자 단위로 맞추고, 문장의 시작/끝은 가까운 **말 시작·말 끝(무음 경계)**에 붙입니다. 두 방식이 어긋나거나(0.4초 넘게) 인식한 글이 대본과 많이 다르면 **노란색(확인 필요)**으로 표시합니다.
   - 음성 인식을 쓸 수 없거나(미설치·실패) 말을 거의 못 알아들으면 **무음 구간만으로** 나눕니다: 말한 구간 수와 자막 수가 같으면 1:1, 다르면 글자 수 비율에 가까운 쉬는 곳에서 합치거나 나눕니다(문장 사이인데 쉬는 곳이 없으면 노란색).
   - **음성 인식 모델**: 기본 `small`(약 485MB). 처음 한 번 인터넷으로 내려받고(진행률 표시) `%LOCALAPPDATA%\VideoComposer\whisper` 에 저장합니다. 그다음부터는 인터넷 없이 내 PC 에서 처리합니다. 더 빠르게는 `tiny`(75MB)/`base`(145MB), 더 정확하게는 `medium`(1.5GB). NVIDIA GPU 가 있으면 자동으로 GPU, 없으면 CPU(int8).
   - **자막 한 개** 20자 × 2줄, **최소 표시** 1.0초가 기본. 자막끼리는 겹치지 않습니다.
5. 녹음은 더빙 트랙에 그대로 남습니다(자막을 다시 만들어도 움직이지 않음). 더빙이 영상보다 길면 알려만 주고 영상 길이는 바꾸지 않습니다.

#### 자막 맞추기 화면 (✏ 자막 맞추기…)
자막 만들기가 끝나면 자동으로 열리고, 나중에 **④ 자막 만들기 ▸ ✏ 자막 맞추기…**로 지금 자막을 다시 열 수 있습니다.
- 왼쪽: 더빙 **파형** 위에 자막 **블록**(밝은 띠 = 말한 구간). 위쪽 줄자, **🔍− / 🔍+** 또는 **Ctrl+휠**로 확대·축소.
  - 블록 **가장자리 끌기** = 시작/끝 조절, **가운데 끌기** = 통째로 옮기기. 말 시작·말 끝에 **자석처럼 붙고**, **Shift** 를 누르고 끌면 자석이 꺼집니다.
  - 블록 **클릭** = 그 자막만 듣기, **더블클릭** = 아래 문구 칸에서 고치기(줄바꿈 = 자막 안의 줄). 빈 곳 클릭 = 빨간 재생 위치 옮기기.
- 오른쪽 **목록**: 번호 · 시작 · 끝 · 대본 문구 · 인식 문구 · 신뢰도. 노란 줄이 확인할 자막(신뢰도에 마우스를 올리면 까닭).
- 버튼: **⚠ 다음 노란색으로**(가서 들려 줌) · **👍 이 자막 확인함**(노란색 끄기) · **▶ 이 자막 듣기** · **✂ 여기서 나누기**(빨간 재생 위치에서 둘로, 문구는 문구 칸 커서 위치 — 없으면 시간 비율에 가까운 띄어쓰기) · **🔗 다음과 합치기** · **⏯ 재생/멈춤** · **↶ 되돌리기 / ↷ 다시 하기**(Ctrl+Z / Ctrl+Y, 모든 편집).
- **⌨ 탭으로 맞추기**: 켜면 선택한 자막 조금 앞부터 재생됩니다. **말이 시작될 때마다 스페이스**(또는 큰 **⏎ 지금 시작!** 버튼)를 누르세요. 누른 시각이 그 자막의 시작이 되고, 이전 자막 끝은 그 사이 말이 끝난 곳(무음 시작 + 0.3초) 또는 다음 시작 직전으로 맞춰집니다. 이번/다음 문구가 크게 보이고, **↺ 선택한 자막부터 다시**로 중간부터 다시 할 수 있습니다.
- **✔ 적용** = 자막 트랙에 넣기(본 화면에서 Ctrl+Z 한 번으로 되돌리기). **취소** = 고친 게 있으면 버릴지 묻습니다.

### 5. 내보내기
위 도구 막대 **📤 영상 내보내기**, **📤 내보내기** 탭 바닥 단추, 또는 **파일 ▸ 영상 내보내기… (Ctrl+E)**
→ "영상 내보내기" 창에서 저장 위치, **영상 크기·fps**, 인코더(자동/GPU/CPU), 움직임 품질 선택 → **📤 내보내기 시작**.
원래 해상도로 만들고, 자막은 스타일대로 영상에 새겨집니다. 진행률과 취소 버튼이 나옵니다.
겹친 더빙 조각이 있으면 시작 전에 한 번 **"더빙 조각이 겹칩니다 — 그래도 내보낼까요?"** 를 묻습니다(겹친 시각 표시, 목소리만 내보내기도 같음, 더빙 트랙 소리를 껐으면 묻지 않음).
**파일 ▸ 목소리만 WAV로 내보내기…** 로 더빙만 따로 저장할 수도 있습니다.

### 6. 대본 출력 (인쇄 · PDF · Word · TXT)
**파일 ▸ 📄 대본 출력… (Ctrl+P)** 또는 툴바 **📄 대본** → 자막으로 녹음·검토용 대본(표)을 만듭니다. 오른쪽에 바로 미리보기가 나옵니다.
- **자막**: 프로젝트 자막(미세 조정한 내용과 전체 오프셋이 반영된 실제 시간) 또는 **다른 SRT/VTT 파일**(프로젝트에 자막이 없으면 자동으로 이쪽)
- **모양**: 제목(기본 = 프로젝트 이름), 글자 크기, 시간 형식 `mm:ss.0`(01:23.4) 또는 `hh:mm:ss,ms`(00:01:23,456)
- **넣을 칸**: 번호, 시작 시간, 끝 시간, 길이, 대본 내용, 녹음 상태 ✔(녹음 파일이 있는 줄), 클립 구간(어느 클립에 나오는지 + 클립이 바뀌는 곳 표시),
  읽기 속도(공백 뺀 글자 수 ÷ 초, 기본 **7자/초를 넘으면 ⚠ 빠름** 빨간색), 메모 칸(빈 칸)
- **내보내기**: 🖨 인쇄… / 인쇄 미리 보기… / **PDF 저장**(한글 글꼴 내장 — 맑은 고딕, 없으면 Noto CJK·나눔고딕 등) /
  **Word(DOCX) 저장**(표, 한글 글꼴 맑은 고딕 지정) / **TXT 저장**(UTF-8, 메모장에서도 안 깨짐) / **📋 클립보드에 복사**(일반 글 + 표 서식)
- A4 용지, 칸이 7개 이상이면 가로 방향으로 인쇄합니다.

## 프로젝트 JSON 형식

정식 JSON Schema: [`schema/project.schema.json`](schema/project.schema.json) · 전체 예시: [`examples/project_example.json`](examples/project_example.json)

시간 단위는 모두 **초**, 파일 경로는 **프로젝트 파일이 있는 폴더 기준 상대 경로**입니다.

```json
{
  "version": 2,
  "title": "여행 브이로그",
  "output": { "width": 1920, "height": 1080, "fps": 30, "fit": "cover", "file": "output.mp4" },
  "transition": { "type": "crossfade", "duration": 0.5 },
  "clips": [
    { "file": "01_바다.png", "type": "image", "duration": 4, "motion": "zoom_in", "motion_strength": 0.15 },
    { "file": "02_산책.mp4", "type": "video", "trim_start": 1, "trim_end": 6, "speed": 1.0, "mute": true,
      "transition": { "type": "fade", "duration": 0.8 } },
    { "file": "03_타임랩스.mp4", "type": "video", "fit_duration": 3.0 }
  ],
  "subtitle": { "file": "자막.srt", "offset": 0.0, "burn_in": true,
                "style": { "font": "Malgun Gothic", "size": 52, "color": "#FFFFFF", "outline": 2.5,
                           "position": "bottom", "margin_v": 70, "box": true, "box_opacity": 0.5,
                           "appear": "fade", "appear_duration": 0.3 } },
  "bgm": { "file": "음악.mp3", "volume": 0.25, "fade_in": 1.5, "fade_out": 3, "loop": true, "duck_under_voice": true },
  "dubbing": { "folder": "takes", "takes": [ { "file": "takes/line_0001_v1.wav", "subtitle": 1, "offset": -2.0 } ] }
}
```

### output (출력)
| 항목 | 기본값 | 설명 |
|---|---|---|
| width, height | 1920, 1080 | 출력 크기(짝수). 세로 쇼츠는 1080×1920 |
| fps | 30 | 프레임 수 |
| fit | `cover` | `cover` 꽉 채우고 넘치는 부분 잘라냄 / `contain` 전체를 보이고 남는 곳은 여백 |
| background | `#000000` | contain 여백 색 |
| original_volume | 1.0 | 모든 클립 원본 소리에 곱하는 전체 볼륨 |
| file | `output.mp4` | 내보낼 때 기본 파일 이름 |
| fade_in / fade_out | 0 / 0 | 영상 시작/끝 검은 화면 페이드 길이(초, 소리도 같이) |

### transition (기본 전환) / clips[].transition (클립별)
클립의 `transition` 은 **이전 클립 → 이 클립**으로 넘어가는 전환입니다. 생략하면 최상위 `transition` 을 씁니다.
- `type`: `none`(바로 전환), `fade`(검은 화면 거치기), `crossfade`(겹치며 바뀜), 그 밖에 ffmpeg xfade 이름
  `wipeleft, wiperight, wipeup, wipedown, slideleft, slideright, slideup, slidedown, circleopen, circleclose, dissolve, smoothleft, smoothright, radial, zoomin`
- `duration`: 전환 길이(초). 전환은 **두 클립 경계 가운데에 걸칩니다**(앞 클립 끝 뒤 절반 + 뒤 클립 시작 앞 절반의 여분 사용). 클립은 맞닿아 이어지므로 **전체 길이 = 클립 길이의 합**이고 전환이 길이를 줄이지 않습니다. 앞뒤 클립 중 짧은 쪽 길이를 넘으면 자동으로 줄어듭니다.
- `version`: `2` 가 지금 형식입니다. `1`(예전: 전환이 두 클립을 겹쳐 놓아 길이가 줄어듦)은 열 때 보이는 시간이 같도록 클립 길이를 전환 절반씩 줄여 자동으로 바꿉니다.

### clips[] (클립)
| 항목 | 기본값 | 설명 |
|---|---|---|
| file | (필수) | 파일 이름 |
| type | 확장자로 추정 | `image` 또는 `video` |
| duration | 4 | **이미지** 표시 시간 |
| motion | `none` | 움직임(이미지·영상): `zoom_in, zoom_out, pan_left, pan_right, pan_up, pan_down, zoom_in_left, zoom_in_right, ken_burns` |
| motion_strength | 0.15 | 움직임 크기 0~1 (0.1~0.25 권장) |
| motion_easing | `ease` | `ease` 부드럽게 가속/감속, `linear` 일정한 속도 |
| speed | 1.0 | **영상** 재생 속도(0.1~16). 소리도 음정 유지하며 같이 바뀝니다 |
| fit_duration | null | 지정하면 이 길이에 맞도록 속도를 자동 계산(speed 무시). 이미지는 duration 대신 사용 |
| trim_start / trim_end | 0 / null | 영상에서 사용할 구간(원본 기준 초). 전환 여분은 이 바깥 원본에서 가져옵니다 |
| motion_from / motion_to | 0 / 1 | 움직임 경로 중 이 클립이 쓰는 부분(✂ 자르기로 나눈 이미지가 이어지게, 보통은 생략) |
| mute | false | 원본 소리 끄기 |
| volume | 1.0 | 원본 소리 크기 |
| fit | null | 이 클립만 `cover`/`contain` 따로 지정 |
| label | "" | 타임라인에 보일 이름표 |
| look | `none` | 색 필터: `none, bw(흑백), sepia(세피아), vintage(빈티지), warm(따뜻하게), cool(차갑게), vivid(선명하게), cinematic(영화톤)` |
| brightness / contrast / saturation | 0 / 1 / 1 | 밝기(-0.5~0.5) · 대비(0.5~2) · 채도(0~3, 0 = 흑백) |
| vignette / blur / grain | 0 / 0 / 0 | 비네팅 · 흐림 · 필름 노이즈 (0~1) |

### subtitle (자막)
| 항목 | 설명 |
|---|---|
| file | SRT 또는 VTT (UTF-8, UTF-8 BOM, CP949/EUC-KR, UTF-16 자동 인식) |
| offset | 모든 자막을 앞뒤로 이동(초, 음수 가능) |
| burn_in | `true` 영상에 글자를 입힘 / `false` 켜고 끌 수 있는 소프트 자막(mov_text) |
| style | 아래 표 참고 |
| items | 프로그램에서 자막을 미세 조정하면 생기는 목록(`index, start, end, text`). 있으면 파일 대신 이것을 씁니다. **수정한 자막을 SRT 로 저장** 버튼으로 내보낼 수 있습니다 |

#### subtitle.style (자막 모양)
| 항목 | 기본값 | 설명 |
|---|---|---|
| font | `"Malgun Gothic"` | Windows 글꼴 이름 |
| size | 48 | 글자 크기(출력 영상 높이 기준 px) |
| bold | true | 굵게 |
| color / outline_color | `"#FFFFFF"` / `"#000000"` | 글자 / 외곽선 색 `#RRGGBB` |
| outline | 2.0 | 외곽선 두께(px) |
| position | `"bottom"` | `bottom`(아래) / `center`(가운데) / `top`(위) |
| margin_v | 60 | 아래·위일 때 가장자리 여백(px) |
| box | false | 글자 뒤 배경 상자 |
| box_color / box_opacity / box_padding | `"#000000"` / 0.6 / 12 | 상자 색, 불투명도(0~1), 여백(px) |
| appear | `"none"` | `none`(그냥) / `fade`(페이드) / `typing`(타이핑) / `slide_up`(아래에서 올라오기) / `pop`(톡 튀어나오기) |
| appear_duration | 0.3 | 효과 시간(초, 0~5) |

AI 프롬프트에도 이 항목들이 안내되어 있어 AI 가 영상 분위기에 맞는 자막 모양을 함께 정할 수 있습니다.

### bgm (배경음악)
`file`, `volume`(0.3), `start_offset`(타임라인에서 시작하는 시점), `file_start`(음악 파일 안에서 시작 위치),
`fade_in`, `fade_out`, `loop`(영상보다 짧으면 반복), `duck_under_voice`(더빙 목소리가 나오면 자동으로 줄이기), `duck_ratio`(줄이는 강도 1~20).

### dubbing (더빙)
`folder`(녹음 파일 폴더), `volume`(목소리 전체 볼륨), `latency_ms`(녹음 지연 보정), `takes[]`:
- `file`: 녹음 WAV
- `subtitle`: 자막 번호(이 자막 시작 시점 기준으로 배치). `null` 이면 `offset` 이 절대 시간(여기부터 연속 녹음·자유 녹음)
- `offset`: 자막 시작 기준 위치(초). 프리롤을 포함해 녹음하므로 보통 `-2.0` 같은 음수
- `volume`: 이 테이크 볼륨
- `trim_start` / `trim_end`: 녹음 파일에서 쓸 구간(파일 기준 초, 기본 0 / 끝까지). ✂ 자르기로 테이크를 나누면 원본 파일은 그대로 두고 이 값만 바뀝니다

`notes`(선택): 녹음본(파일)별 이름·★ — `{"takes/line_0001_v2.wav": {"name": "밝게", "star": true}}`. 🛠 더빙의 녹음본 목록에서 ✎·☆ 로 바뀌며, 프로그램이 관리합니다.

자막을 옮기면 연결된 더빙 테이크도 같이 움직입니다.

### tracks (트랙 켜고 끄기 — 프로그램이 관리, AI 는 안 써도 됨)
`"tracks": {"clips": {...}, "subtitle": {...}, "dubbing": {...}, "bgm": {...}}`, 각각 `hidden`·`muted`·`solo`·`locked` (true/false, 기본 false).
없으면 모두 꺼진 상태(= 다 보이고 다 들림)로 읽습니다. 자막에는 `hidden`·`locked` 만, 더빙·배경음악에는 `muted`·`solo`·`locked` 만 쓰입니다.

## 떨림 방지 원리

ffmpeg 의 흔한 방법(`zoompan`)은 매 프레임 잘라낼 위치를 **정수 픽셀로 반올림**합니다. 그래서 천천히 움직이면
"0, 0, 1, 0, 0, 1 픽셀"처럼 불규칙하게 움직여 떨려 보입니다. 이 프로그램은

1. 이미지를 출력 크기의 2배(설정에 따라 1~3배)로 고품질 확대한 뒤,
2. `perspective` 필터로 잘라낼 영역의 네 꼭짓점을 **소수점 좌표**로 매 프레임 계산해 bicubic 보간으로 샘플링하고,
3. 마지막에 출력 크기로 lanczos 축소합니다.
4. 줌·위치는 프레임 번호에 대한 연속 함수(선형 또는 코사인 이징)이고, 모든 클립은 같은 고정 fps 로 맞춥니다.

`tests/test_render_e2e.py` 에서 위상 상관(phase correlation)으로 프레임 간 이동량을 재서 확인합니다.
같은 패닝을 측정한 결과(프레임 간 이동량의 불규칙성, 0 에 가까울수록 매끄러움): 일반 zoompan **약 0.68px**,
zoompan 4배 확대 **약 0.30px**, 이 프로그램 **약 0.06px**(중간 파일 기준).

## 렌더 구조와 캐시

1. 각 클립을 같은 해상도·fps·yuv420p·48kHz 스테레오로 맞춘 중간 파일(`.composer_cache\clip_*.mkv`)로 만듭니다.
   클립 설정과 원본 파일이 같으면 다시 만들지 않습니다(전환·자막·음악·더빙만 바꾸면 클립은 전부 캐시 사용).
2. 중간 파일들을 xfade/acrossfade/concat 으로 잇고, 자막·더빙·배경음악을 섞어 최종 파일을 만듭니다.
- 미리보기는 360p + 빠른 설정이라 금방 끝납니다. 내보내기는 원래 해상도로 다시 만듭니다.
- 캐시가 커지면 **내보내기 ▸ 캐시 비우기**.
- NVIDIA 그래픽카드가 있으면 `h264_nvenc` 를 자동으로 씁니다(실제로 인코딩이 되는지 시험한 뒤 선택). 없으면 `libx264`.
- 렌더 로그는 `.composer_cache\work_final\*.log` (미리보기는 `work_draft`) 에 남습니다.

## 알아 둘 점 / 제한

- 자막이 나타나고 사라질 때 미리보기 화면이 흔들리던 문제를 고쳤습니다(오른쪽 더빙 패널의 자막 글 길이가 화면 배치를 바꾸던 것). 자막·진행 표시·안내는 영상 위에 그리기만 하므로 영상 크기·위치는 바뀌지 않습니다.
- 미리보기 화면은 360p 렌더 영상입니다. 편집 후 다시 만들어지기까지 몇 초 걸리며, 그동안에는 이전 미리보기가 보입니다(자막·더빙 위치는 즉시 반영).
- 미리보기에서 더빙 테이크는 실시간으로 함께 재생되지만, 재생 도중 테이크 중간으로 이동하면 그 테이크는 다음 재생부터 들립니다.
- 녹음 타이밍은 사운드 장치 지연에 따라 수십 ms 어긋날 수 있습니다. **녹음 지연 보정** 또는 테이크 오프셋으로 맞추세요.
- 고해상도(1080p 이상) 이미지 움직임은 계산량이 많습니다(8코어 CPU 기준 4초 클립에 약 9초). "빠르게(1배)" 품질로 줄일 수 있습니다.
- 자막 글꼴은 Windows 에 설치된 글꼴 이름을 씁니다(기본 `Malgun Gothic` / 맑은 고딕). 영상을 내보낼 때 `C:\Windows\Fonts` 도 찾아봅니다. 없는 글꼴이면 비슷한 글꼴로 바뀝니다.
- 애니메이션 GIF 는 첫 프레임만 이미지로 사용합니다.
- 음성 인식(faster-whisper)은 첫 사용 때 모델을 내려받아야 합니다(인터넷 필요, small 약 485MB). 설치되어 있지 않거나 쓸 수 없으면 무음 감지만으로 자막을 나눕니다. 잡음이 많거나 아주 작은 소리는 잘 못 알아들을 수 있으니 노란색 자막을 꼭 들어 보세요.
